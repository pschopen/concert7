Overview

Concert7 has two kinds of controls. Some change the impulse response itself – they are marked Rebuilds IR below. When you move one of them, Concert7 re-synthesises the response in the background and cross-fades to it after a moment, so you hear the new setting fade in rather than change instantly. All other controls work in real time on the reverb signal.

Signal flow

  1. Input
  2. Propagation
  3. Convolution with the designed IR
    early · pre-delay · late · delay voices
  4. Modulation
  5. Post EQ

  7. Mix with dry

Modulation, EQ and ducker only affect the reverb (wet) signal. The dry signal is untouched until it is mixed back in.

Handling

  • Knobs are turned by dragging up/down or left/right.
  • Double-click a knob to return it to its default value.
  • All controls are automatable and stored with your DAW project. Concert7 has no user presets of its own (yet) – use your DAW's preset function.

Display & presets

The top bar shows the current preset and lets you browse the library.

Dot matrix display

Top line: bank and preset number (e.g. HALLS 01) and the source file – its sample rate (44K / 48K) and TS for a true stereo (quad) capture or ST for a plain stereo one. The large line is the preset name, the bottom line the current decay time. The graph on the right draws the envelope of the designed impulse response with its length in seconds. Click the display to open a menu of all presets, sorted by bank.

Bank buttons

Banks
Halls · Plates · Rooms · Chambers · Ambience · Spaces

Each button opens the presets of one bank; the LED shows which bank the current preset is from. Your own impulse responses (any other audio files in the IR folder) appear in an additional User bank.

< Browse >

The arrows step to the previous / next preset. Browse opens the full preset menu.

A newly selected preset starts at its own native decay time (analysed RT60 of the recording). Turn on Hold decay when changing presets to keep your decay setting instead.

Status LED

Below the logo: READY when impulse responses are installed, NO IRS when the library is missing – then click the display or use the setup menu to install it.

Main controls

The six large knobs are always visible.

Pre-delay

Rebuilds IR
Range
0 – 500 ms
Default
0 ms

Delays the late reverb relative to the dry signal and the early reflections. A few tens of milliseconds separate the reverb from the source and keep vocals and instruments clear and in front; long pre-delays create a distinct gap, like a large space with far walls.

With Sync turned on, the pre-delay follows the host tempo and is set with Pre-delay note instead.

Decay

Rebuilds IR
Range
0.2 – 30 s
Default
native RT60 of the preset

The reverb time (RT60): how long it takes the late reverb to fall by 60 dB. Concert7 reshapes the recorded tail to the new slope – shorter values make it fall faster, longer values extend it beyond the end of the recording with a synthesised tail that keeps the preset's spectrum.

The decay is the reference for the multi-band decay multipliers. Presets with an abrupt, gated envelope keep their cut-off when lengthened and get a longer tail after it.

Early

Rebuilds IR
Range
Off (–24 dB) – +6 dB
Default
0 dB

Level of the early reflections – the first ≈ 80 ms after the direct sound, which carry most of the information about the size and shape of the room. Raise it for a sense of space and proximity; turn it down (or off) for a smooth tail without a distinct room. All the way left switches the early reflections off.

Late

Rebuilds IR
Range
Off (–24 dB) – +6 dB
Default
0 dB

Level of the late reverb – the dense, diffuse tail after the early reflections. Together with Early it sets the balance between room character and reverb wash. All the way left switches the tail off, leaving only the early reflections (useful for ambience).

Mix

Range
0 – 100 %
Default
30 %

Balance between the dry input and the reverb. At 0 % the output is the unchanged input (bit transparent), at 100 % only the reverb.

On an aux / send track set Mix to 100 % and control the amount with the send level.

Gain

Range
–24 – +12 dB
Default
0 dB

Output level after the mix – it affects dry and wet signal alike. Use it to match the level of long or very dense presets.

In / Out meters

Peak meters for the left and right input and output channels.

Reverb page

Shape the structure of the reverb: early reflections, the late tail, delay voices and how the stereo channels are fed in.

Early reflections

Pattern

Rebuilds IR
Range
Preset, 1 – 32
Default
Preset

Selects which early reflections are used. Preset keeps the preset's own. Patterns 1 – 32 take the early part of other presets in the library, ordered from short to long. This combines the tail of one space with the reflections of another – for example a plate tail with the reflections of a small room.

Roll-off

Rebuilds IR
Range
80 Hz – 20 kHz, Off
Default
Off

Low pass filter for the early reflections only. Lower values make the reflections darker and less prominent, as if the walls were absorbing more high frequencies. At the right end (20 kHz and above) the filter is off.

Late reverb

Roll-off

Rebuilds IR
Range
80 Hz – 20 kHz, Off
Default
Off

Low pass filter for the late reverb. Taming the top end of the tail is one of the most effective ways to make a reverb sit behind the mix. It changes the tone, not the decay time – to make highs die away faster, use High mult instead.

VLF

Rebuilds IR
Range
Off (–21 dB) – 0 dB
Default
0 dB

Very low frequency level: the level of the late reverb below ≈ 120 Hz. Turn it down to keep the low end of the mix clean and avoid boomy tails, especially on bass-heavy sources. All the way left removes the very low frequencies from the tail.

Delay

Time

Rebuilds IR
Range
100 ms – 1 s
Default
250 ms

Spacing of the delay voices. With Sync on, the time follows the host tempo and is set with Delay note.

Level

Rebuilds IR
Range
Off (–21 dB) – 0 dB
Default
Off

Turns on three repeats of the late reverb, each one Time later than the previous one and attenuated by Level again – at –6 dB the voices come at –6, –12 and –18 dB. This creates rhythmic, echoing tails, like a reverb fed into a delay. Off by default.

Sync · Delay note

Rebuilds IR
Notes
1/64 – 1/2, triplet (T) and dotted (D)
Default
Off · 1/8

Sync locks the delay time to the host tempo; Delay note chooses the note value.

Pre-delay / routing

Sync · Pre-delay note

Rebuilds IR
Notes
1/64 – 1/2, triplet (T) and dotted (D)
Default
Off · 1/16

Sync locks the pre-delay to the host tempo; Pre-delay note chooses the note value. While sync is on, the pre-delay knob is greyed out (the same applies to the delay Time knob).

Propagation

Modes
True Stereo · No Crossfeed · Mono In
Default
True Stereo

How the input channels feed the reverb:

  • True Stereo – four convolution paths (L→L, L→R, R→L, R→R) as recorded by the quad captures. A source panned left also excites the right side of the room, exactly as in the original hardware.
  • No Crossfeed – only L→L and R→R. The reverb keeps the stereo position of the source more strictly and sounds narrower and more defined.
  • Mono In – left and right are summed before the reverb. Useful for mono sources or to get a centred, balanced reverb from a stereo signal.

Decay page

Multi-band decay: make the reverb time frequency dependent, like a real room in which highs are absorbed faster than lows. The graph shows the resulting reverb time over frequency; the LOW and HIGH marks are the two crossover frequencies.

Low freq

Rebuilds IR
Range
80 Hz – 4.8 kHz
Default
400 Hz

Crossover frequency of the low band. Below it, Low mult applies; the transition is smooth.

Low mult

Rebuilds IR
Range
×0.2 – ×4
Default
×1.00

Multiplies the decay time of the low frequencies. Values above ×1 give a warm, long bass tail (large halls, churches); values below ×1 tighten the low end so the reverb doesn't muddy the mix.

High freq

Rebuilds IR
Range
200 Hz – 16 kHz
Default
4 kHz

Crossover frequency of the high band. Above it, High mult applies.

High mult

Rebuilds IR
Range
×0.2 – ×4
Default
×1.00

Multiplies the decay time of the high frequencies. Below ×1 the tail gets darker as it decays – natural and unobtrusive; above ×1 it becomes airy and shimmering, like a bright plate.

The multipliers are relative to the main Decay knob: with a decay of 3 s and High mult ×0.5, the highs decay in 1.5 s.

EQ page

A five band equaliser for the reverb signal (the dry signal is not affected). Each band can be set with its knobs or directly on the curve:

  • Drag a point to change frequency and gain. Dragging the HP or LP point switches that filter on.
  • Mouse wheel over a point changes its Q (bandwidth).
  • Double-click a point to reset its gain to 0 dB, or to switch HP / LP on and off.

EQ

Default
On

Switches the whole EQ on or off – handy to compare with and without.

High pass · HP / Freq

Range
20 Hz – 2 kHz, 12 dB/oct
Default
Off · 80 Hz

Removes everything below the frequency from the reverb. The classic first move to keep a reverb from clouding kick, bass and the low mids.

Low · Type / Freq / Gain / Q

Freq
20 Hz – 1 kHz
Gain
±18 dB
Q
0.3 – 6
Default
Shelf · 200 Hz · 0 dB · 0.71

Shelf raises or lowers everything below the frequency, Bell only a band around it. Q sets the steepness of the shelf or the width of the bell (higher = narrower).

Mid · Freq / Gain / Q

Freq
100 Hz – 10 kHz
Gain
±18 dB
Q
0.3 – 6
Default
1 kHz · 0 dB · 1.0

A bell filter for the middle range, e.g. to cut boxy 300 – 500 Hz or harsh 2 – 4 kHz resonances of a preset.

High · Type / Freq / Gain / Q

Freq
1 – 20 kHz
Gain
±18 dB
Q
0.3 – 6
Default
Shelf · 6 kHz · 0 dB · 0.71

Shelf raises or lowers everything above the frequency, Bell only a band around it.

Low pass · LP / Freq

Range
1 – 22 kHz, 12 dB/oct
Default
Off · 12 kHz

Removes everything above the frequency. Unlike the late roll-off it acts on the finished reverb signal, including early reflections, modulation and delay voices, and works in real time.

Mod / Duck page

Movement and dynamics for the reverb signal.

Modulation

Depth

Range
0 – 100 %
Default
0 % (off)

Amount of a slow pitch modulation (vibrato) on the reverb. Left and right are modulated with a 90° offset, which adds width and movement and smooths out metallic ringing in sustained tails. Because there is no dry path inside the modulator, it does not cause comb filtering. Keep it low for natural spaces.

Rate

Range
0.05 – 4 Hz
Default
0.5 Hz

Speed of the modulation. Slow rates sound like a gentle drift, fast rates with a lot of depth become an audible chorus or vibrato.

Ducker

The ducker lowers the reverb while the input is playing and lets it swell up in the gaps – long reverbs on vocals or leads without washing out the words.

Amount

Range
Off – –40 dB
Default
Off

Maximum reduction of the reverb while the key signal is above the threshold.

Threshold

Range
–60 – 0 dB
Default
–30 dB

Level at which ducking starts. The reduction fades in over a soft knee of 6 dB above the threshold and reaches the full Amount 6 dB above it. Attack is fast (a few milliseconds).

Release

Range
20 ms – 3 s
Default
300 ms

How quickly the reverb comes back after the key signal falls below the threshold. Short values let the reverb pop up between words, long values make it swell in slowly.

Sidechain

Default
Off

Off: the plugin's own input controls the ducker. On: the sidechain input is used instead – route another track to Concert7's sidechain in your DAW, for example to duck a reverb bus whenever the lead vocal sings. Without a sidechain connected, the input is used.

Setup menu

The Setup button at the right of the page tabs opens the settings. These settings are stored on your computer for all instances, not in the DAW project.

Impulse responses

  • The first line shows the current IR folder.
  • Choose IR folder… – use a folder with impulse responses you unpacked yourself.
  • Install impulse responses (ZIP)… – opens the setup screen to install the Samplicity ZIP archive.
  • Rescan library – reads the folder again, e.g. after you added your own impulse responses.

Hold decay when changing presets

Default
Off

Off: each preset starts at its own native decay time. On: the Decay setting is kept when you switch presets – handy to compare spaces at the same length.

Interface size

Sizes
75 · 100 · 125 · 150 · 200 %

Scales the whole window.

Reset all parameters

Sets every control back to its default and reloads the current preset at its native decay.

Version and credits.

Library folders: macOS ~/Library/Application Support/Concert7/Impulse Responses, Windows %APPDATA%\Concert7\Impulse Responses, Linux ~/.config/Concert7/Impulse Responses. Concert7 uses the 44.1 kHz files at 44.1/88.2/176.4 kHz and the 48 kHz files at 48/96/192 kHz; other sample rates are resampled once when a preset loads.
